# PHASES
- Phase 1 (original implementation target: 60%): foundation + core scan workflow + multimodal interfaces + deterministic decision + tests + docs + PWA. This percentage is a planning milestone, not a measurement of accuracy, readiness, or completion. The current app has a functional demo workflow, with explicit limitations.
- Remaining work before research-grade claims: validate OCR/date parsing on a held-out package-label set; collect grouped, repeated freshness observations; train and compare vision/fusion/shelf-life models; calibrate physical sensors; report independent metrics and failure cases. These items cannot be represented as complete without data and evaluation.
- Phase 2 (roadmap): controlled Day0→DayN aging dataset, sensor calibration, trained MobileNetV3/EfficientNet, learned/ablated fusion (early/feature/late), shelf-life regression (RF/XGBoost/neural/LSTM), Grad-CAM, ONNX/TFLite edge quant, full benchmarking.
